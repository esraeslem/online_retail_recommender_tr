# Veri

Bu proje **Online Retail II** veri setini kullanır (`online_retail_II.xlsx`, `Year 2010-2011` sayfası).

Ham dosya (~45 MB) bu repoya dahil edilmemiştir. Kodu çalıştırmak için:

1. Dosyayı [UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/502/online+retail+ii) üzerinden indirin (ya da [Kaggle mirror](https://www.kaggle.com/datasets/mashlyn/online-retail-ii-uci)).
2. Dosyayı `data/online_retail_II.xlsx` konumuna yerleştirin.
